INFORMAÇÃO E TRANSPARÊNCIA

Política de Privacidade.

Esta página explica, de forma geral, como funciona a interação com este site.

Última atualização: 8 de outubro de 2026

1. Sobre este site

Este é um site institucional de Deusvaldo de Oliveira, criado para apresentar o trabalho de decoração e facilitar o contato com a equipe.

2. Informações enviadas por você

O site não possui, nesta versão, formulário próprio de cadastro ou compra. Ao clicar em um link de WhatsApp, você será direcionado ao serviço WhatsApp, que poderá receber a mensagem que você decidir enviar. Evite compartilhar dados pessoais desnecessários.

3. Dados técnicos e hospedagem

O site foi preparado para publicação como páginas estáticas. O serviço de hospedagem pode registrar dados técnicos de acesso, como endereço IP, para finalidades de segurança e operação, conforme as políticas do provedor. Consulte a Política de Privacidade do GitHub se o site estiver hospedado no GitHub Pages.

4. Cookies e ferramentas de análise

Esta versão do site não instala deliberadamente ferramentas próprias de publicidade, pixels de marketing ou analytics. Serviços externos acessados por links podem aplicar suas próprias tecnologias e políticas.

5. Serviços de terceiros

Os links para WhatsApp, Instagram, TikTok e Facebook levam a plataformas de terceiros. O uso desses serviços é regido pelos termos e políticas de cada plataforma, fora do controle deste site.

6. Segurança e atualizações

São adotadas medidas razoáveis no desenvolvimento do site, mas nenhum sistema conectado à internet pode ter sua segurança absoluta garantida. Esta política poderá ser atualizada quando novas funcionalidades forem adicionadas, como formulários, métricas ou recursos comerciais.

7. Dúvidas e solicitações

Para dúvidas relacionadas a esta política, entre em contato com a equipe pelo WhatsApp.

Nota de implementação: este texto corresponde à versão inicial sem formulários, contas, pagamentos ou ferramentas de rastreamento próprias. Se essas funcionalidades forem adicionadas, a política deve ser revisada antes da publicação da nova versão.
